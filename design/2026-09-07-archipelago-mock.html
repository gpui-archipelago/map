The GPUI fork map

(crates.io cross-fork alignment & empirical measurement)

Every fork is an island. There’s no mainland and no one’s building one, so the islands have to find each other. Here they can.

Zed's UI framework is republished on crates.io as six packages (gpui, gpui-ce, gpui-unofficial, gpui-pre, kael, gpui-box) under incomparable version numbers. This map answers the questions names cannot:

Three Truth Layers

Separation of attestation
Layer What the map shows Origin
Registry truth Published versions, yanked / prerelease flags, declared rust-version (never an attestation). live crates.io sync
Measured Per-version item surfaces (kind:name + digest), whole-surface hashes. syn-level corpus analysis
Not yet measured Derives, trait interfaces, auto-traits, compiler floors, cfg evaluations — shown as not measured, never guessed. phase 3 rustdoc passes

Honest Display Rules (RULE-1 to RULE-7)

  • RULE-1: Epochs are exact-copy-only within a stream. No cross-fork "same generation" badges exist anywhere on this site.
  • RULE-2: Items are qualified kind:name. Doc comment edits count toward a type's digest as re-signatures.
  • RULE-5: Compile-verified badges appear only where real projects were compiled against crates.io artifacts.
